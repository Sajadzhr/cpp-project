معرفی پروژه:
-------------
این یک برنامه تعاملی است که ورودی را از کاربر دریافت می‌کند. برنامه یک منو
نمایش می‌دهد و به کاربر اجازه می‌دهد:
- عملیات مورد نظر را انتخاب کند
- ابعاد ماتریس/بردار را وارد کند
- مقادیر عناصر را وارد کند
- نتایج را فوراً مشاهده کند
- عملیات‌های مختلف را بدون نیاز به راه‌اندازی مجدد امتحان کند

فایل‌های این پروژه:
---------------------
1. matrix_library.h      - فایل هدر شامل اعلان توابع
2. matrix_library.cpp    - پیاده‌سازی همه توابع کتابخانه
3. demonstration.cpp     - برنامه اصلی تعاملی با منو
4. test_cases.txt     - نمونه تست‌ها (فقط برای مرجع)
5. README.txt           - همین فایل

عملیات‌های پیاده‌سازی شده:
-----------------------------

عملیات ماتریسی:
1. جمع (A + B)
2. تفریق (A - B)
3. ضرب (A * B)
4. ضرب اسکالر (k * A)
5. ترانهاده (A^T)
6. دترمینان (det(A)) - فقط برای ماتریس‌های 1x1، 2x2، 3x3
7. معکوس (A^(-1)) - فقط برای ماتریس‌های 2x2

عملیات برداری:
8. جمع (u + v)
9. تفریق (u - v)
10. ضرب اسکالر (k * u)
11. ضرب داخلی (u · v)
12. ضرب خارجی (u × v) - فقط برای بردارهای سه‌بعدی
13. اندازه (|u|)
14. نرمال‌سازی (بردار واحد)

نحوه کامپایل:
--------------
g++ -o matrix_program demonstration.cpp matrix_library.cpp
یا از خود کد بلاکس

نحوه اجرا:
----------
چه اتفاقی می‌افتد وقتی برنامه را اجرا می‌کنید:
-----------------------------------------------
1. برنامه منویی با 14 عملیات نمایش می‌دهد (0 برای خروج)
2. شما یک عدد (1-14) را انتخاب می‌کنید
3. برنامه ورودی می‌خواهد (ابعاد، عناصر)
4. شما مقادیر را وارد می‌کنید
5. برنامه نتیجه را نمایش می‌دهد
6. Enter می‌زنید تا به منو برگردید
7. تکرار کنید یا 0 را برای خروج انتخاب کنید


مدیریت خطا:
------------
برنامه همه موارد خطا را مدیریت می‌کند:
- عدم تطابق ابعاد برای جمع/تفریق
- ابعاد نامعتبر برای ضرب
- ماتریس‌های غیرمربعی برای دترمینان
- ماتریس‌های منفرد (دترمینان = 0) برای معکوس
- بردارهای غیر سه‌بعدی برای ضرب خارجی
- بردارهای صفر برای نرمال‌سازی

محدودیت‌ها:
------------
1. حداکثر ابعاد ماتریس: 100 x 100
2. حداکثر اندازه بردار: 100 عنصر
3. دترمینان: فقط ماتریس‌های 1x1، 2x2، 3x3
4. معکوس ماتریس: فقط ماتریس‌های 2x2
5. ضرب خارجی: فقط بردارهای سه‌بعدی
